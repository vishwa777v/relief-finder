# 🚑 Relief Finder

A fast, minimalist web app to locate the nearest hospitals, police stations, and pharmacies using your live GPS location.

## 📌 About

Relief Finder is built for moments that matter — when someone needs to quickly find the nearest emergency service without digging through maps or search results. Just open the app, allow location access, and instantly see nearby help.

## ✨ Features

- 📍 Detects your current location using GPS
- 🏥 Finds nearest hospitals
- 🚓 Finds nearest police stations
- 💊 Finds nearest pharmacies
- ⚡ Clean, minimal, easy-to-use interface

## 🛠️ Built With

- **HTML** — structure
- **CSS** — styling
- **JavaScript** — app logic and interactivity
- **Google Maps API** — location detection and nearby-place search
